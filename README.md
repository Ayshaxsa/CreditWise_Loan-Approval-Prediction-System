# Credit Loan Approval Prediction System

## 📌 Project Overview
This project predicts whether a loan application will be approved using Machine Learning models.

The goal is to compare multiple classification models and select the best-performing one.

---

## 🧠 Models Used
- Naive Bayes
- K-Nearest Neighbors (KNN)
- Logistic Regression

---

## 📊 Model Performance

### 🔹 Naive Bayes
- Accuracy: 0.89
- Precision: 0.90
- Recall: 0.67
- F1 Score: 0.77

### 🔹 KNN
- Accuracy: 0.73
- Precision: 0.50
- Recall: 0.49
- F1 Score: 0.50

### 🔹 Logistic Regression (Best Model)
- Accuracy: 0.895
- Precision: 0.84
- Recall: 0.76
- F1 Score: 0.80

---

## 🏆 Best Model
Logistic Regression performed best based on F1-score and overall balance.
